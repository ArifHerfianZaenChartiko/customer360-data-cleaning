# Raw Data

The raw CSVs are stored as `raw_data.zip` because GitHub rejects files over 100 MB (`clickstream_500k_events.csv` is 121.8 MB).

Extract `raw_data.zip` in this folder before running the notebooks. The five CSVs will land here directly:

| File | Rows |
|---|---:|
| `crm_50000_customers_dirty_v3.csv` | 50,000 |
| `product_catalog_dirty_30pct.csv` | 500 |
| `orders_300k_dirty.csv` | 300,000 |
| `support_tickets_30000_dirty.csv` | 30,000 |
| `clickstream_500k_events.csv` | 500,000 |

Source: Kaggle "Customer 360" by vinaykandimalla (CC0, synthetic data). These files are read-only and are never modified.
